## ✨ Tentang Project

**WarungDigital** adalah platform web modern yang menggabungkan **toko produk digital** dengan **sistem donasi real-time**. Dibangun dengan teknologi web modern tanpa framework berat — ringan, cepat, dan responsif.

> 🎯 Cocok buat kreator yang mau jualan produk digital sekaligus nerima donasi dari pendukung.

---

## 🚀 Fitur Utama

| Fitur | Deskripsi |
|-------|-----------|
| 🛍️ **Katalog Produk** | Grid produk digital dengan kategori & harga |
| 💚 **Donasi Real-Time** | Notifikasi donasi masuk otomatis via webhook Tako |
| 📊 **Statistik Live** | Total donasi, jumlah donatur, jumlah produk |
| 🔔 **Toast Notification** | Notif popup tiap ada donasi baru masuk |
| 📱 **Fully Responsive** | Tampilan rapi di HP, tablet, dan desktop |
| 🎨 **UI Modern** | Dark theme premium dengan animasi halus |
| ⚡ **Zero Framework** | HTML + CSS + JS murni, super ringan |
